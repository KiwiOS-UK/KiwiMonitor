See what your rig is actually doing.

I built KiwiMonitor because I kept alt-tabbing mid-raid just to check if my GPU was throttling. It reads your real sensors — CPU, GPU, temps, clocks, RAM, VRAM, fans — and puts them on a HUD you can leave open on a second monitor, no cloud account required to run it.

What you get

Built for the rig, not the demo

No telemetry dashboard in the cloud, no account tier that unlocks "premium sensors." Just a bridge that reads your hardware and a page that shows it.

Updates every second

CPU/GPU load, temps and clocks refresh in real time — no five-second lag pretending to be "live."

AMD or Intel, either GPU

Built on LibreHardwareMonitor, so it isn't locked to one vendor's tool the way Ryzen Master or MSI Afterburner are.

Stays on your PC

The bridge talks to your sensors and your browser — that's the whole trip. Nothing gets phoned home.

It's just HTML and JS

Open dashboard.html in a text editor and change whatever you want — colors, layout, which sensors show up.

Why this exists

I was three raid pulls deep, alt-tabbing every few minutes to check if my GPU was actually the bottleneck or if it was just me playing badly. Task Manager doesn't show clocks or temps. Afterburner's overlay works, but it's tied to one vendor's ecosystem and I wanted something I could poke at myself.

So — a small local server that reads LibreHardwareMonitor, and a dashboard that shows it. That's genuinely the whole thing. No accounts on the actual monitoring tool, no data leaving your PC, nothing to configure beyond turning on one setting in LibreHardwareMonitor.

The sign-up on this page is just for the install guide below, mostly so I can see who's using it. The tool itself has never asked anyone to log in to anything.

Questions

Before you ask in the comments

Does any of this send data off my PC?

The monitoring tool itself, no — the bridge reads LibreHardwareMonitor and hands numbers straight to the dashboard on your machine. The only thing that leaves your PC is what you type into the sign-up form on this page (email, username, and hardware fields, if you fill them in) — that's covered in the Privacy Policy.

Why do I need to install LibreHardwareMonitor separately?

Because reading real sensors properly is its own hard problem, and LibreHardwareMonitor already does it well across AMD, Intel, and every major GPU vendor. Rebuilding that from scratch for one dashboard didn't make sense.

Can I see real in-game FPS on here?

Not yet. Hardware sensors can't see frame rate — that needs a render-hook tool like RivaTuner or PresentMon, which works completely differently from sensor polling. It's on the list.

A sensor shows "--" instead of a number. Is it broken?

Probably just a naming difference — sensor names vary a bit across BIOS/driver versions. Open localhost:8085/data.json to see your raw sensor tree, and check the README for how the matching rules work.

Is the desktop installer signed?

No — that needs a paid certificate I haven't bought yet. Windows/macOS will show a first-run security warning; that's expected for a personal build, not a sign anything's wrong.

Privacy Policy

Last updated: July 2026

This is written in plain language on purpose, so it's clear about both what's collected and the real limits of how it's protected — not a legal document reviewed by counsel.

What's collected

  • Username and email address, when you sign up
  • A password hash and a random per-account salt — never your actual password
  • CPU and GPU model, if you choose to enter them
  • Account creation time

How it's stored

Everything above lives in this page's built-in storage, in a space shared across everyone who uses this app — that's what lets you log back in from a different visit. It is not a dedicated database with row-level access control: there's no separate encryption at rest, and the admin view on this page is only protected by a password check that runs in your browser, not a server-side permission system. Treat this like a hobby project's data handling, not a bank's.

How it's used

Solely to run the account gate for the install tutorial, and to let the maintainer see who's signed up and what hardware they're running, for support and interest — not sold, not shared with advertisers, not used for anything beyond this app.
